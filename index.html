Tentang proyek

Plugin Manager menyediakan skrip dan perangkat bantu untuk mengelola plugin Infinite Yield. Repositori GitHub adalah sumber kode dan informasi proyek.

Beberapa proyek pendukung dapat menyediakan fitur otomasi atau integrasi layanan pihak ketiga. Penggunaan fitur tersebut tunduk pada izin dan penjelasan yang ditampilkan saat fitur digunakan.
